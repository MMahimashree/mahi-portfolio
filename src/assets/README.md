# Portfolio assets

Replace these placeholder paths with your own files:

- `profile.jpg` — your profile photo (used in the hero)
- `project-1.png` — Mahi Orbit screenshot (featured project)
- `project-2.png` — MedBot screenshot (featured project)
- `resume.pdf` — your downloadable resume

The app shows an elegant fallback when an image or PDF is not present. Update text, links, projects, skills, achievements, and teaching topics in `src/data/portfolio.ts`.
